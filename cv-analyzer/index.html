Overview

CV Platform (also presented as Draftline in the UI) is an early-stage resume-processing application.

  1. A user submits a resume;

  2. the backend stores the original,

  3. backend queues an extraction job,

  4. system makes processing updates available to the browser.

Documentation map

  • Architecture context describes the running components and their boundaries.

  • Processing workflow follows a job from upload through extraction and status delivery.

  • Data and persistence describes what is stored, where, and for how long.

  • Service catalog distinguishes implemented services from prototypes.

  • Uploader and Extractor document each service’s behavior.

  • Configuration and Operations cover environment variables and local operation.

  • Service contracts records the HTTP, queue, and status-event shapes.
