= Overview

CV Platform (also presented as Draftline in the UI) is an early-stage resume-processing application. A user submits a resume; the backend stores the original, queues an extraction job, and makes processing updates available to the browser.

The implemented backend consists of two Go services: an HTTP uploader and a RabbitMQ-driven extractor. The UI is a React application. The current backend workflow extracts text from PDFs and images and stores that text in S3-compatible object storage.
