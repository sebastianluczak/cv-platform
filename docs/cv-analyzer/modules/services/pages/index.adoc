= Service Catalog

[cols="1,2,2,1"]
|===
|Component |Role |Runtime status |Documentation

|`uploader`
|HTTP upload endpoint, object-storage writer, queue publisher, and SSE status server
|Implemented; part of the running upload/extraction flow
|xref:uploader.adoc[Uploader]

|`extractor`
|RabbitMQ consumer for PDF and image text extraction; queues redaction after extraction
|Implemented; part of the running upload/extraction flow
|xref:extractor.adoc[Extractor]

|`piistripper`
|RabbitMQ consumer that writes a separate best-effort redacted text result
|Implemented; part of the extraction/redaction flow
|xref:piistripper.adoc[PII stripper]

|`skillmatcher`
|Scores redacted resume text against deterministic IT role-profile patterns
|Implemented; part of the running upload/review flow
|xref:skillmatcher.adoc[Skill matcher]

|`offermatcher`
|Compares the active resume's saved skill evidence with a pasted or fetched job offer
|Implemented; asynchronous offer comparison after resume matching
|xref:offermatcher.adoc[Offer matcher]

|`aiweighter`
|Creates a tailored Markdown resume from a completed offer match after explicit user consent
|Implemented; optional asynchronous AI resume generation
|xref:aiweighter.adoc[AIweighter]

|`roleinsights`
|Suggests evidence-grounded occupations from a redacted resume after explicit user consent; independent of technical scores
|Implemented; optional asynchronous role insights
|xref:roleinsights.adoc[Role insights]
|===
