= Prototype Components

== Skill matcher

`services/skillmatcher` currently contains only a README describing an intended post-extraction skill-matching step. There is no Go implementation, input/output contract, executable, or connection from the extractor. Skill matching is not part of the running workflow.

== AI weighter

`services/aiweighter/aiweighter.go` contains a standalone helper that sends supplied text to OpenRouter's chat-completions endpoint. It selects a model directly in source and prints the response content, reasoning field, and full response body. It requires `OPENROUTER_API_KEY` and panics on errors.

This package is not wired into the upload/extraction flow, has no service module or independently declared Go module, and should be treated as experimental code rather than a production service. If invoked with resume text, it sends that content to an external provider. Review data handling, provider terms, error behavior, model configuration, and logging before integrating it.

== Before connecting a prototype

Define an explicit input/output contract, ownership of retries and failures, privacy and retention behavior, and operational configuration. Update the architecture and data-lifecycle pages when the running service boundaries change.
