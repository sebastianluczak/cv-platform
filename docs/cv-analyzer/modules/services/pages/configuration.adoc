= Configuration

The uploader and extractor must point to the same RabbitMQ queue and S3-compatible storage namespace.

[cols="1,1,2,2"]
|===
|Variable |Required by |Default |Purpose

|`RABBITMQ_URL`
|Uploader, extractor
|None
|AMQP connection URL. Required at startup.

|`QUEUE_NAME`
|Uploader, extractor
|None
|Durable extraction queue name. Status and failed queue names are derived by appending `.events` and `.failed`.

|`RUSTFS_ENDPOINT_URL`
|Uploader, extractor
|`http://localhost:9000`
|S3-compatible endpoint.

|`RUSTFS_BUCKET`
|Uploader, extractor
|`cv-platform-uploads`
|Shared bucket for original uploads and extracted text.

|`RUSTFS_REGION`
|Uploader, extractor
|`us-east-1`
|S3 signing region.

|`RUSTFS_ACCESS_KEY_ID`
|Uploader, extractor
|`rustfsadmin`
|Object-storage access key.

|`RUSTFS_SECRET_ACCESS_KEY`
|Uploader, extractor
|`rustfsadmin`
|Object-storage secret key.

|`PORT`
|Uploader
|`8080`
|HTTP listen port.

|`OPENROUTER_API_KEY`
|`aiweighter` prototype only
|None
|API key required if the standalone `SendToWeighter` helper is called.
|===

Defaults for S3 credentials are suitable only for local development. Use dedicated least-privilege credentials and a secret-management mechanism appropriate to the deployment; do not commit real credentials. The uploader attempts to list buckets and create the configured bucket if it is missing, so its credentials need the corresponding permissions.

Use the same `RUSTFS_*` values in both services. In particular, `RUSTFS_BUCKET` must match or the extractor rejects the job reference.
