= Configuration

The uploader, extractor, and piistripper must point to the same RabbitMQ queue and S3-compatible storage namespace.

[cols="1,1,2,2"]
|===
|Variable |Required by |Default |Purpose

|`RABBITMQ_URL`
|Uploader, extractor, piistripper
|None
|AMQP connection URL. Required at startup.

|`QUEUE_NAME`
|Uploader, extractor, piistripper
|None
|Durable extraction queue name. Redaction, status, and failed queue names append `.pii`, `.events`, `.failed`, and `.pii.failed`.

|`RUSTFS_ENDPOINT_URL`
|Uploader, extractor, piistripper
|`http://localhost:9000`
|S3-compatible endpoint.

|`RUSTFS_BUCKET`
|Uploader, extractor, piistripper
|`cv-platform-uploads`
|Shared bucket for original uploads, extracted text, and redacted results.

|`RUSTFS_REGION`
|Uploader, extractor, piistripper
|`us-east-1`
|S3 signing region.

|`RUSTFS_ACCESS_KEY_ID`
|Uploader, extractor, piistripper
|`rustfsadmin`
|Object-storage access key.

|`RUSTFS_SECRET_ACCESS_KEY`
|Uploader, extractor, piistripper
|`rustfsadmin`
|Object-storage secret key.

|`PORT`
|Uploader
|`8080`
|HTTP listen port.

|`OPENROUTER_API_KEY`
|`aiweighter` prototype only
|None
|API key required if the standalone `SendToWeighter` helper is called.
|===

Use the same `RUSTFS_*` values in all three services. In particular, `RUSTFS_BUCKET` must match or a worker rejects the job reference. Piistripper consumes `<QUEUE_NAME>.pii` and writes a separate redacted result.
