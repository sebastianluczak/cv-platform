= ADR-0004: Use of SSE for user-level notifications

Traditionally, a web page has to send a request to the server to receive new data; that is, the page requests data from the server. With server-sent events, it's possible for a server to send new data to a web page at any time, by pushing messages to the web page. These incoming messages can be treated as Events + data inside the web page.

== Context

In this project, all jobs are asynchronous. User only truly waits for data upload and the process starts.

As it progresses, we want real status updates for user in UI.

== Decision

This project uses SSE to communicate with the client.

== Consequences

Browser creates a session with SSE.
